# Design: add-toolbox-script-create

## Context

### 现状

| 模块 | 路径/能力 | 与本变更关系 |
|------|-----------|--------------|
| 工具箱页 | `src/pages/toolbox/toolbox-page.tsx` | 注册 `video-merge` / `image-crop`；需扩展 `script-create` |
| Modal | `ToolboxToolModal`：`max-w-2xl` 默认，`max-h-[min(90vh,760px)]` 写死 | 剧本工具需加宽加高 |
| 工坊 Step1 | `step1-script-page.tsx`：编辑/导入 `script`，无 AI 生成 | 成功出口对接点 |
| 数据模型 | `WorkflowProjectData.script: string`，`SCRIPT_MAX_LENGTH=50000` | 送工坊只写纯文本 |
| 视觉风格 | `EpisodeStyle = realistic \| comic \| 2d_anime \| 3d_anime \| article` | 与「甜宠/悬疑」叙事题材正交 |
| LLM | `callChatCompletions` 非流式，`signal?: AbortSignal`，默认 `haodouReason=consume_script` | Phase 0 直接复用 |
| 导入 | `extractScriptTextFromFile`（txt/md/docx 读入） | Phase 1 改编模式复用 |
| 导出 docx | 仓库无写出能力 | v1 不做 |
| 模板 | `extractTemplates` / `styleTemplates` / `storyboardTemplates` | v1 不扩 settings schema |
| 创建项目 | `createWorkflowProject` + `navigate(/workshop/:id/step/1)` | 送工坊主路径 |

### 约束

- 蓝图：不做「我的剧本」独立入口
- Renderer 无 Node；本地文件经既有 IPC/选择器模式
- 最小 diff；对齐现有 toolbox 工具组件分层
- **产品原则**：默认一句话出稿、参数折叠、结果可扫、单主 CTA 送工坊

## Goals / Non-Goals

### Goals

1. **一分钟出草稿，三分钟能送走**（空态 → 生成 → 送工坊）
2. 默认零决策负担：一句话 + 智能默认参数即可生成
3. 结果先可扫（摘要）再可改（全文真源）
4. 唯一主成功路径：**送入创作工坊**（复制/导出为逃生舱）
5. 与工坊数据模型兼容（平文本 `script`）
6. 首个 AI 工具箱能力：配置/扣豆/取消/失败体验完整
7. Phase 0 可独立上线验证飞轮

### Non-Goals（本变更明确不做）

- 独立剧本库 / 历史草稿列表页（Phase 2+）
- 覆盖当前已打开工坊项目的剧本
- 预填 Step2 `episodes[]`
- LLM streaming（用预期文案 + 骨架进度代替）
- docx 导出
- 设置页可编辑 `scriptTemplates`
- 画布分镜节点直连
- 打开即三模式并列 Tab（改编/润色为 Phase 1 次级入口）
- 结构化卡片与全文双写编辑

## Product definition

### 一句话

> 用一句话生成能拍的短剧剧本，满意就送进创作工坊接着做。

### 不是

> 专业剧本工作台，支持多模式结构化创作与导出。

### 卡片文案（工具箱列表）

| 字段 | 文案 |
|------|------|
| 标题 | 剧本创作 |
| 描述 | 一句话生成可拍剧本，一键送进创作工坊 |
| 角标 | AI（与本地裁剪/合并区分） |
| id | `script-create` |
| Modal 副标题 | 快速出稿；满意后可新建工坊项目继续分集与分镜 |

### 品类心智

| 工具 | 类型 |
|------|------|
| 视频合并 / 图片裁剪 | 本地处理 |
| 剧本创作 | **AI 生成**（可能耗时、可能扣豆） |

侧栏暂不拆分；靠卡片 AI 角标区分即可。

## Product UX / Interaction Spec

### UX 原则（实现必须遵守）

1. **默认零参数**：主路径只暴露创意输入 + 生成；条件以一行芯片摘要展示，点「改条件」才展开
2. **一个主按钮**：结果态主 CTA 仅为「送入创作工坊」；复制/导出为次级
3. **全文为唯一编辑真源**：摘要/场次列表只读派生，禁止双写
4. **生成器不是工坊**：不提供分集/资产/分镜，不提供多剧本库
5. **预期管理**：AI、耗时、可能消耗在空态或生成前可见

### 默认参数（用户未改条件时）

| 参数 | 默认值 |
|------|--------|
| 内容类型 | 漫剧短剧 |
| 目标时长 | 60 秒 |
| 集数 | 单集 |
| 叙事题材 | 不限 / 通用（prompt 不强绑题材） |
| 平台 | 抖音竖屏 |

芯片摘要示例：`60秒 · 竖屏 · 漫剧 · 单集`

### 状态机

```text
                    ┌──────────────┐
          打开工具  │              │  hydrate 草稿
        ──────────►│  boot        │──────────────┐
                    └──────┬───────┘              │
                           ▼                      ▼
                    ┌──────────────┐       ┌─────────────┐
                    │ empty        │◄──────┤ result      │ 清空/再写一版
                    │ （无全文）    │       │ （有全文）   │
                    └──────┬───────┘       └──────▲──────┘
                           │ 生成                 │ 成功
                           ▼                      │
                    ┌──────────────┐       ┌──────┴───────┐
                    │ generating   │──────►│ error        │
                    │              │ 失败  │ （保留旧全文）│
                    └──────┬───────┘       └──────────────┘
                           │ 取消
                           ▼
                    回到 empty 或 result（以取消前是否有全文为准）
```

| 状态 | 进入条件 | 界面要点 |
|------|----------|----------|
| `empty` | 无全文（含新用户或用户清空） | 沉浸输入；主按钮「生成剧本」 |
| `generating` | 已发起 LLM | 骨架 + 耗时预期 + 取消；禁用送工坊 |
| `result` | 有非空全文 | 摘要 + 全文编辑 + 底栏主 CTA 送工坊 |
| `error` | 本次生成失败 | Toast/内联错误；若曾有全文仍停在可编辑结果 |

关闭 Modal：

- `generating` → 二次确认 → abort → 关闭
- 其他状态 → 直接关闭（草稿已 autosave）

### 状态 A — 空态 `empty`

**布局：单栏沉浸（非双栏参数墙）**

```text
┌──────────────────────────────────────────────┐
│ [AI] 剧本创作                                 │
│ 一句话生成可拍剧本，一键送进创作工坊            │
├──────────────────────────────────────────────┤
│ 想拍一个什么故事？                             │
│ ┌──────────────────────────────────────────┐ │
│ │ 占位：女主重生复仇，60 秒三个反转…         │ │
│ └──────────────────────────────────────────┘ │
│                                              │
│ [60秒·竖屏·漫剧·单集]  改条件 ▾               │
│   └─ 展开后：时长 / 集数 / 类型 / 题材 / 平台 │
│                                              │
│            【 生成剧本 】                     │
│                                              │
│ 小字：使用 AI 生成，约 15～40 秒；可能消耗好豆 │
│                                              │
│ 试试：                                       │
│  [重生打脸]  [职场反转]  [甜宠误会]            │
│                                              │
│ （未配置模型时主区域提示，见下）                │
└──────────────────────────────────────────────┘
```

**文案**

| 位置 | 文案 |
|------|------|
| 主标题区提问 | 想拍一个什么故事？ |
| 输入占位 | 例如：女主重生复仇，60 秒里要有三个反转 |
| 主按钮 | 生成剧本 |
| 消耗提示 | 使用 AI 生成，大约 15～40 秒；按账号策略可能消耗好豆 |
| 示例芯片 | 重生打脸 / 职场反转 / 甜宠误会（点击填入完整示例句，可再改） |
| 改条件 | 改条件 |

**示例句（可写死）**

1. 重生回到婚前，当众揭穿渣男，60 秒三个反转  
2. 社畜被领导甩锅，电梯监控反转打脸  
3. 青梅竹马假装情侣参加同学聚会，假戏真做  

**未配置 LLM**

- 不进入「点了才报错」：空态展示引导条  
- 文案：`还没有可用的对话模型。请先到 设置 → 模型配置 中添加或启用模型。`  
- 按钮：`去配置模型` → `/settings` 对应 Tab（与现网设置路由对齐）  
- 「生成剧本」禁用或点击同引导  

**校验**

- 创意 trim 为空 → toast「先写一句故事想法」不发起请求  

### 状态 B — 生成中 `generating`

```text
┌──────────────────────────────────────────────┐
│ 正在写分场剧本…                               │
│ 大约还要半分钟，你可以取消                     │
│                                              │
│ ░ 标题骨架                                    │
│ ░ 角色骨架                                    │
│ ░ 场次 1 / 2 / 3 灰条                         │
│                                              │
│            【 取消 】                         │
└──────────────────────────────────────────────┘
```

- 创意与条件区只读或禁用编辑（避免用户以为改了会作用到本次请求）  
- 非流式：骨架为假进度，不假装百分比精确  
- 取消：`AbortSignal`；toast「已取消」；回到 empty 或 result  

### 状态 C — 结果态 `result`

**布局：上摘要（只读）+ 下全文（可编辑）+ 底栏固定操作**

```text
┌──────────────────────────────────────────────┐
│ 摘要卡（只读，解析失败则折叠为仅标题/字数）      │
│  标题 · 一句话卖点                             │
│  约时长 · N 场 · M 个角色                      │
│  · 场次1标题  · 场次2标题  · 场次3标题 …       │
├──────────────────────────────────────────────┤
│ 标题 [可编辑，作项目名候选]                     │
│ ┌──────────────────────────────────────────┐ │
│ │ Markdown 全文（真源）                      │ │
│ │                                          │ │
│ └──────────────────────────────────────────┘ │
│ 字数 n / 50000                               │
├──────────────────────────────────────────────┤
│ [再生成] [再短一点]   [复制] [导出]  【送入创作工坊 →】 │
└──────────────────────────────────────────────┘
```

**摘要规则**

- 从全文 Markdown 尽力解析：`# 标题`、卖点行、`### 场次`、角色列表  
- 解析失败：**不报错打断**；摘要区仅显示字数与「已生成剧本」  
- 摘要字段只读，点击不进入逐字段编辑  

**底栏动作**

| 动作 | 级别 | 行为 |
|------|------|------|
| 送入创作工坊 → | **主 CTA** | 见 D6；视觉最重 |
| 复制 | 次级 | 剪贴板全文 |
| 导出 | 次级 | `.txt` |
| 再生成 | 次级 | 同创意同参数再请求；确认是否覆盖全文（有改动时） |
| 再短一点 | 次级 Phase 0 可做轻量 | 预置润色 prompt 压篇幅；Phase 0 若排期紧可放到 Phase 1 |

**结果态仍可改条件再生成**：提供「改想法」链回强调输入区（可折叠顶栏保留创意）。  

### 状态 D — 错误 `error`

| 错误类型 | 文案方向 |
|----------|----------|
| 网络/超时 | 生成失败，请检查网络后重试 |
| 401/Key | 模型密钥无效，请到设置检查 |
| 余额/好豆 | 与现有 `formatLlmHttpError` / 好豆提示一致 |
| 空返回 | 模型没有返回内容，请重试或换模型 |

- 提供【重试】  
- 若失败前已有全文：保留全文，用户仍可送工坊  

### 送入工坊 — 确认与成功

**点击主 CTA 前校验**

- 全文非空  
- 非 generating  
- dataRoot 等与工坊创建一致  

**可选轻确认（推荐 Phase 0 用 toast 进度，不加重弹窗）**

- 进行中按钮 loading：`正在创建工坊项目…`  

**成功**

- `navigate(/workshop/{id}/step/1)`  
- 关闭工具 Modal  
- 工坊内可用 sonner：`剧本已就绪。下一步可在分集步骤继续制作。`  
- **不强制清空**工具箱草稿  

**项目默认标题优先级**

1. 用户编辑的标题字段  
2. 从全文解析的 `# 标题`  
3. 创意前 20 字  
4. `未命名剧本`  

### 次级能力入口（避免一级 Tab 抢路径）

| 能力 | Phase | 入口位置 |
|------|-------|----------|
| 灵感生成 | 0 | 默认主路径 |
| 素材改编 | 1 | 输入区上方文字链「改用素材改编」或「更多方式 ▾」 |
| 润色改写 | 1 | 同上；结果态「再短一点」可走润色管道 |
| 视觉风格 EpisodeStyle | 1 | 送工坊前可选，不进默认芯片 |

### 可访问与边界文案

| 场景 | 文案 |
|------|------|
| 空创意生成 | 先写一句故事想法 |
| 空全文送工坊 | 还没有剧本可送入，请先生成或粘贴 |
| 超字数 | 剧本最多 50000 字 |
| 生成中关窗 | 剧本还在生成，确定关闭并停止吗？ / 继续等待 / 关闭并停止 |

## Decisions（技术）

### D1. 产品定位

**工具箱 = 轻量生成器；工坊 = 制作流水线。**

- 草稿：临时态（localStorage 单份）
- 成功态：导出文件，或工坊项目内的 `script`

### D2. 数据真源

```
真源 = 可编辑全文 Markdown（string）
摘要 / 场次列表 = 从全文解析的只读派生
送工坊 / 导出 = serialize(全文) → 纯文本，截断至 SCRIPT_MAX_LENGTH
```

### D3. 输出约定（Prompt + 序列化）

```markdown
# {标题}

> 一句话卖点：...
> 预估时长：...

## 角色
- 角色名：人设一句

## 第1集 {集标题}

### 场次1 · {地点} · 约Ns
- 画面：...
- 对白/旁白：...
- 情绪：...
```

多集仅影响 prompt 文内标记；落库仍是一篇 `script`。

### D4. 参数维度

| 维度 | 示例 | 默认暴露 |
|------|------|----------|
| 内容类型 | 漫剧短剧 / 口播剧情 / 反转短片 | 折叠进「改条件」 |
| 目标时长 | 15s / 60s / 3min | 默认 60s，芯片可见 |
| 集数 | 单集 / 3 集 | 默认单集 |
| 叙事题材 | 甜宠 / 悬疑 / … | 折叠，默认不限 |
| 平台 | 抖音竖屏 / 公众号 | 默认竖屏 |
| EpisodeStyle | realistic… | Phase 1 送工坊时可选 |

### D5. 创作模式

| 模式 | Phase | 入口 |
|------|-------|------|
| 灵感生成 | 0 | 默认 |
| 素材改编 | 1 | 更多方式 |
| 润色改写 | 1 | 更多方式 / 再短一点 |

同一 `callChatCompletions` 管道，不同 prompt。

### D6. 送入工坊流程

```text
校验全文非空、未在生成中
  → createWorkflowProject({ title })
  → session.load(projectId)
  → patchData({ script, style? })
  → save（若需要）
  → 关闭 Modal
  → navigate(`/workshop/${projectId}/step/1`)
  → toast 引导 Step2
  → 工具箱草稿保留
```

不做「覆盖当前项目」。

### D7. LLM 与扣豆

- `pickMergedLlmModel` + `callChatCompletions(..., { signal, haodouReason: "consume_script" })`
- 未配置：空态引导，不静默失败
- 失败保留上次成功全文

### D8. Prompt 存放

- Phase 0/1：`src/lib/toolbox/script-create/prompt.ts` 常量
- 强调可拍、可画、对白短、分场与秒数
- 不扩 settings `TemplateListKey`

### D9. 草稿

- Key：`haode.toolbox.script-create.draft.v1`（可加 userId 后缀）
- 字段：idea、params、title、script、updatedAt、uiMode
- debounce autosave；仅一份

### D10. UI 实现结构（对应 UX 状态，而非一上来永久双栏）

```text
ScriptCreateTool
  empty/generating：单栏主路径
  result：摘要 + 全文 + 底栏（可用大 Modal 双分区，但不是左参数右文的专业台默认态）
```

Modal：`max-w-5xl` + `maxHeightClassName` 加高（如 `max-h-[min(92vh,900px)]`）。

### D11. 代码分层

```text
src/components/toolbox/script-create-tool.tsx
src/lib/toolbox/script-create/
  types.ts
  prompt.ts
  serialize.ts
  draft-storage.ts
  generate.ts
  parse-preview.ts    # 摘要解析，失败降级
```

### D12. 分期

| 阶段 | 范围 |
|------|------|
| Phase 0 | 空态单栏、默认参数芯片、生成/取消/骨架、结果摘要+全文、复制/导出 txt、草稿、送工坊、模型引导、AI 角标 |
| Phase 1 | 更多方式（改编/润色）、EpisodeStyle 送工坊、时长粗检、再短一点（若 0 未做） |
| 后续 change | 历史草稿、streaming、docx、设置模板、画布联动 |

### D13. 成功指标

| 指标 | 含义 |
|------|------|
| 生成完成率 | 点生成 → 有正文 |
| **送工坊转化率** | 有正文 → 进工坊（北极星） |
| **送工坊后 Step2 操作率** | 可制作性 |
| 复制/导出率 | 逃生舱使用 |
| 二次打开草稿率 | 是否当半成品编辑器 |

## Risks / Trade-offs

| 风险 | 缓解 |
|------|------|
| 与 Step1 心智重叠 | 文案强调快速出稿 / 送工坊；不做库 |
| 参数过重劝退 | 默认折叠 + 芯片摘要 |
| 长文不可信 | 只读摘要 + prompt 可拍约束 |
| 非流式体感卡死 | 15～40 秒预期 + 骨架 + 取消 |
| 双写状态 | 全文真源，摘要只读 |
| 主路径被复制/导出稀释 | 底栏视觉权重：主 CTA 唯一突出 |

## Migration

- 无数据迁移；无 settings schema 变更
- 蓝图「不做我的剧本独立入口」仍成立
