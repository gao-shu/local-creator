# Delta for toolbox

## ADDED Requirements

### Requirement: 剧本创作工具入口

系统必须在工具箱卡片列表中提供「剧本创作」工具（id: `script-create`），并以 **AI 类工具** 的方式与本地媒体工具区分展示。

#### Scenario: 展示剧本创作卡片
- **WHEN** 用户打开 `/toolbox`
- **THEN** 可见标题为「剧本创作」的卡片
- **AND** 描述传达「一句话生成可拍剧本，一键送进创作工坊」
- **AND** 卡片具有 AI 角标或等价视觉标识

#### Scenario: 打开剧本创作工具
- **WHEN** 用户点击「剧本创作」卡片
- **THEN** 系统打开工具 Modal 并渲染剧本创作工具
- **AND** 不直接进入创作工坊四步流水线页

### Requirement: 工具 Modal 支持加宽加高

系统必须允许工具箱 Modal 配置更大宽度与高度，且不得破坏视频合并、图片裁剪的默认尺寸。

#### Scenario: 默认工具尺寸不变
- **WHEN** 用户打开视频合并或图片裁剪
- **THEN** Modal 仍使用既有默认最大宽度与高度

#### Scenario: 剧本工具使用更大尺寸
- **WHEN** 用户打开剧本创作工具
- **THEN** Modal 使用加宽加高尺寸
- **AND** 主操作在可视区域内可达

## MODIFIED Requirements

### Requirement: 工具箱不承载完整创作流水线

工具箱工具必须保持「完成一件事」的心智；不得在工具箱内实现创作工坊 Step2～Step4 的完整流水线。

剧本创作工具仅作为 **AI 生成器**：成功出口为复制、导出，或 **新建** 工坊项目写入 Step1；不得提供独立「我的剧本」列表。

#### Scenario: 剧本工具出口合法
- **WHEN** 用户完成剧本生成
- **THEN** 可复制或导出
- **AND** 可送入新的创作工坊项目
- **AND** 不能在工具箱内管理多剧本归档列表

#### Scenario: 不在工具箱内做分集分镜
- **WHEN** 用户使用剧本创作工具
- **THEN** 不提供 Step2/3/4 完整流水线能力
