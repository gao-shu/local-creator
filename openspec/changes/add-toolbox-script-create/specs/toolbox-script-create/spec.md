# Delta for toolbox-script-create

## ADDED Requirements

### Requirement: 产品主路径为一句话生成

系统必须将「灵感一句话生成」作为默认主路径；默认状态下不得要求用户先填写完整参数表或先选择多种创作模式。

#### Scenario: 空态默认单栏
- **WHEN** 用户首次打开剧本创作且无全文草稿
- **THEN** 界面以创意大输入与「生成剧本」为主
- **AND** 生成条件以摘要芯片展示（如 60秒·竖屏·漫剧·单集）
- **AND** 详细参数位于「改条件」折叠区内，默认不全部展开

#### Scenario: 默认参数可直接生成
- **WHEN** 用户只输入创意、不打开「改条件」并点击生成
- **THEN** 系统使用默认参数发起生成（默认：60 秒、竖屏、漫剧短剧、单集）

#### Scenario: 示例创意
- **WHEN** 用户点击示例芯片
- **THEN** 创意输入框填入对应完整示例句且可继续编辑

### Requirement: 创作模式不得抢占主路径

Phase 0 必须仅提供灵感生成主路径。Phase 1 若增加素材改编、润色改写，必须以次级入口呈现（如「更多方式」），不得在默认空态以三个并列一级 Tab 抢占主路径。

#### Scenario: Phase 0 无三模式一级 Tab
- **WHEN** 交付 Phase 0
- **THEN** 默认界面不展示「灵感 / 改编 / 润色」并列一级 Tab

### Requirement: 灵感生成剧本

系统必须支持用户输入一句话创意与（可选展开的）生成参数，调用已配置 LLM 生成 Markdown 可拍摄剧本文本。

#### Scenario: 成功生成
- **WHEN** 已配置可用 LLM 且创意非空并点击生成
- **THEN** 进入生成中状态并在成功后写入非空全文
- **AND** 进入结果态

#### Scenario: 未配置模型空态引导
- **WHEN** 用户打开工具且无可用 LLM
- **THEN** 空态展示前往模型配置的引导
- **AND** 不依赖用户点击生成后才首次得知未配置

#### Scenario: 空创意
- **WHEN** 创意为空用户点击生成
- **THEN** 系统提示先填写想法且不发起请求

#### Scenario: 取消生成
- **WHEN** 生成中用户取消
- **THEN** 中止请求并返回取消前状态（empty 或 result）

#### Scenario: 生成失败保留旧稿
- **WHEN** LLM 失败且此前已有全文
- **THEN** 展示可读错误且保留旧全文

### Requirement: 生成中体验

生成过程中系统必须提供耗时预期说明、可感知的等待界面（如骨架）以及取消能力；不得在无反馈情况下长时间空白。

#### Scenario: 生成中文案与取消
- **WHEN** 处于生成中
- **THEN** 展示类似「正在写分场剧本」及约半分钟预期
- **AND** 提供取消
- **AND** 送入工坊不可用

### Requirement: 生成参数维度

系统必须提供与工坊 `EpisodeStyle` 正交的参数：内容类型、目标时长、集数、叙事题材、平台。叙事题材不得与 `EpisodeStyle` 混为同一控件。

#### Scenario: 改条件影响 prompt
- **WHEN** 用户展开改条件并修改参数后生成
- **THEN** 请求包含对应约束

#### Scenario: 多集输出单篇全文
- **WHEN** 用户选择多集并生成成功
- **THEN** 结果仍为单篇 Markdown
- **AND** 文中含可识别分集标记
- **AND** 不写入 `episodes[]`

### Requirement: 结果态摘要只读且全文为真源

结果态必须提供便于 10 秒决策的只读摘要（尽力解析标题、卖点、场次等），以及可编辑全文。全文为复制、导出、送工坊的唯一真源；摘要不得成为第二套可编辑数据。

#### Scenario: 编辑全文生效
- **WHEN** 用户修改全文
- **THEN** 复制/导出/送工坊使用修改后的全文

#### Scenario: 摘要解析失败降级
- **WHEN** 全文无法解析出场次结构
- **THEN** 摘要降级展示且不阻断编辑与送工坊

#### Scenario: 字数上限
- **WHEN** 全文将超过 `SCRIPT_MAX_LENGTH`（50000）
- **THEN** 系统阻止或截断并提示，与工坊 Step1 对齐

### Requirement: 底栏主 CTA 为送入工坊

结果态必须提供「送入创作工坊」作为视觉与交互上的主操作；复制与导出必须为次级操作。

#### Scenario: 主次动作
- **WHEN** 用户处于结果态
- **THEN** 主按钮文案为送入创作工坊（或等价）
- **AND** 同时提供复制与导出 txt

### Requirement: 复制与导出

系统必须支持复制全文与导出 `.txt`。

#### Scenario: 复制与导出
- **WHEN** 全文非空并执行复制或导出
- **THEN** 内容与当前全文一致（截断规则适用时除外）

### Requirement: 本地临时草稿

系统必须本地持久化当前一份草稿（创意、参数、全文等），关闭再开可恢复；不得提供多剧本归档列表页。

#### Scenario: 自动保存与恢复
- **WHEN** 用户编辑后关闭再打开工具
- **THEN** 恢复上次草稿

#### Scenario: 非剧本库
- **WHEN** 使用本工具
- **THEN** 无「我的剧本」多条目管理界面

### Requirement: 送入创作工坊

系统必须支持将当前全文 **新建** 为工坊项目 Step1 剧本并跳转 Step1；v1 不得覆盖其他已打开项目剧本。

#### Scenario: 送入成功
- **WHEN** 全文非空且用户点击送入且前置条件满足
- **THEN** 创建新项目并写入 `script`
- **AND** 导航至 `/workshop/{projectId}/step/1`
- **AND** 关闭工具 Modal
- **AND** 提示剧本已就绪可继续分集

#### Scenario: 项目标题优先级
- **WHEN** 送入成功
- **THEN** 项目标题按 标题字段 > 解析标题 > 创意前 20 字 > 「未命名剧本」 决定

#### Scenario: 空文本或生成中不可送入
- **WHEN** 全文为空或正在生成
- **THEN** 送入被拒绝或不可用

#### Scenario: 失败保留现场
- **WHEN** 创建或写入失败
- **THEN** 提示错误且草稿与全文不变

#### Scenario: 送入后不强制清空草稿
- **WHEN** 送入成功
- **THEN** 不强制清空工具箱本地草稿

### Requirement: 生成中关闭需确认

#### Scenario: 生成中关闭
- **WHEN** 生成中用户关闭 Modal
- **THEN** 需确认；确认后 abort 并关闭

### Requirement: 扣豆与消耗语义

LLM 调用必须复用 `consume_script` 消耗语义，不得绕过既有守卫。

#### Scenario: 系统模型消耗
- **WHEN** 使用需好豆的系统 LLM 生成
- **THEN** 走与 `callChatCompletions` 一致的消耗路径

### Requirement: Phase 1 次级模式（分期）

Phase 1 可以提供素材改编与润色，且必须从次级入口进入。

#### Scenario: 次级入口
- **WHEN** Phase 1 启用改编/润色
- **THEN** 默认空态主路径仍是一句话生成
- **AND** 改编/润色不通过三个并列一级 Tab 作为默认信息架构

### Requirement: Phase 1 送工坊携带视觉风格（分期）

Phase 1 送入时可可选 `EpisodeStyle` 写入 `style`；不得替代叙事题材参数。

#### Scenario: 携带 style
- **WHEN** 用户选择视觉风格并送入成功
- **THEN** 项目 `style` 为所选值且 `script` 仍为纯文本全文
