# 00 · 产品目标与边界

## 1. 一句话

把「好的漫创」桌面端能力，变成与公司后台无关、可自用/熟人安装、**代码可开源**的本地产品（占位名：**本地漫创** / `local-creator`）。

## 2. 已确认决策（2026-09-07）

| # | 决策 |
|---|------|
| 代码来源 | 先写文档；确认后再从 `haode-ai-client` **整仓迁入**（方案 A） |
| 能力目标 | **L2**（自用 + 熟人安装包） |
| 公司功能 | **删除代码**，不是开关隐藏（服务开源干净） |
| 品牌 | 占位：`local-creator` / 本地漫创；**暂不对外公开仓库** |
| 文档读者 | 人 + AI |
| 与公司关系 | **完全脱离**；本仓→开源版；另仓→商业版 |
| 更新 | 后期 Gitee + 自有网盘；第一期可关自动更新 |
| Cursor | 暂时仍打开 `haode-ai-client` 工作区，**只写本目录文件** |

## 3. L2 必须具备

- 无公司登录 / 好豆 / 系统模型代理仍可完成：剧本→资产→分镜→生图/生视频（依赖用户自备第三方 API）
- 自定义 LLM / 图片 / 视频模型配置
- 微视等**用户自备 Key** 的直连能力可保留（属第三方，不是公司后台）
- Windows 安装包可安装、可卸载、数据在本地目录
- 安装包与源码中**不出现**公司运营后台强依赖路径（删除后编译通过）

## 4. L2 明确不做（二期 / 商业版）

- 即梦本地（Playwright + SESSION_ID 非官方桥）
- 完全离线本地大模型推理
- 微信登录 / 短信登录对接公司或自建账号体系（开源版可无账号）
- 好豆充值、公司系统模型商城
- 自动更新上线（可先关；Phase 6 后再接 Gitee/网盘）

## 5. 开源版 vs 商业版（远期）

```text
haode-ai-client     公司仓（只读参考，不向其提交本地版）
        │
        ▼ 迁入并清洗
local-creator       开源版主干（删公司耦合）
        │
        ▼ 另开仓库（Phase 8）
local-creator-pro   商业版（授权、更新、增值功能）
```

开源版原则：**能删的公司逻辑物理删除**；商业能力不回流污染开源主干。
