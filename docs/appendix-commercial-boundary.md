## 1. 开源核（本仓库，MIT）

开源核必须在**无任何商业模块**的情况下可独立安装、编译、运行，并完成主路径：

**剧本 → 分集 → 资产 → 分镜 →（剪映导出 / 后续最小 MP4）**，模型由用户自备 Endpoint + API Key。

### 1.1 能力范围（开源核包含）

| 能力 | 说明 |
|------|------|
| 创作工坊 | 四步流水线 |
| 无限画布 | 节点式图/视频/提示词编排 |
| 本地数据根 | 用户自选存储目录；项目与设置落盘本地 |
| BYOK 模型 | LLM / 图片 / 视频等用户自配（含 OpenAI 兼容等） |
| 剪映/CapCut 草稿导出 | 旗舰成片交接（D5） |
| 最小导出 MP4 | D5 要求；在 OB3 实现，属开源核能力而非商业壳 |
| FFmpeg 基础 | 探测 / 抽音等本地媒体能力 |
| 免登录 | 无强制云账号 |

### 1.2 典型目录（开源核）

| 路径 | 角色 |
|------|------|
| `electron/` | 主进程、preload、IPC |
| `src/` | 渲染进程业务与 UI |
| `scripts/` | 构建与验证脚本 |
| `docs/` | 产品与阶段文档 |
| `examples/` | 示例项目（OB 起） |
| `LICENSE` / `NOTICE` | 许可与第三方声明 |

## 2. 商业壳（另议，本期不落代码）

按 D2，商业模块关系**后期再定**。在定案前遵守：

1. **不在本公开树**加入「去掉后无法 compile / 无法完成主路径」的闭源必选依赖。  
2. 未来优先倾向：**另仓专有**实现商业能力，经稳定接口（如 hooks / 可选插件包）注入；公开 README 不得暗示「开源版不能导出/不能用工坊」。  
3. 候选商业能力（OC 再选，D6=`OC 再定`）：精品模板订阅、优先支持、可选云同步、团队协作等。  
4. **禁止**：阉割开源核逼氪；托管代扣 API 未单独立项前不作默认切口。

### 2.1 未来加载方式（草案，未实现）

```text
开源仓（MIT）── 稳定 no-op 接口（可选）
                │
                └── 另仓 / 私有包（专有许可）实现真正商业逻辑
```

OA/OB 阶段：接口与另仓均可不存在；仅保留本边界文档。

## 3. 贡献者许可

向本仓库提交代码、文档或其他材料，即视为贡献者同意以本仓库根目录 `LICENSE`（MIT）授权给项目及下游用户。  
若后续引入 CLA 或变更许可证，须在变更说明中单独公告，且不追溯已按 MIT 分发的版本义务之外的限制。

## 4. 第三方服务免责

- 用户配置的模型 / 云 API 之费用、配额、内容合规与服务条款，由用户与该服务商自行承担。  
- 本软件不提供云充值、不代理公司计费后台。  
- 剪映/CapCut 为第三方产品；导出草稿的兼容性随其版本变化，开源核按「尽力而为」维护。

## 5. 托管与品牌（执行约束）

| 项 | 锁定 |
|----|------|
| 许可证 | MIT |
| 公开托管 | 双发：主 Gitee，镜像 GitHub（公开须人授权，默认 OA 内不公开） |
| 品牌 | OA 仍用占位「本地漫创」；正式名与 appId 在 OB 前另改 |

## 6. 硬性验收句（给审核）

> **开源核可独立运行**：在不安装任何商业壳、不连接项目自有付费后端的前提下，本仓库 `npm run compile` 可通过，且用户自备 Key 后能完成至少一条生图或分镜相关主路径。
