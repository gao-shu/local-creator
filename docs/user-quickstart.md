# 本地漫创 · 快速上手（试用）

## 源码启动

```bash
npm install
npm run dev
```

## 配置模型（必做）

第三方 API **费用自理**；本软件不提供云模型或充值。

1. 打开 **设置 → 模型**。
2. **LLM**：添加模型 → OpenAI 兼容 → 填 Endpoint + API Key + 模型名（如 Agnes）。
3. **图片 / 视频**：同样添加 OpenAI 兼容（或智谱 / Grok 等预设），填好 Endpoint 与 Key。
4. 点「测试」确认连通后再去工坊 / 画布生成。

## 安装包（若有人发给你 Setup）

1. 运行 `本地漫创 Setup x.x.x.exe`。
2. 打开「本地漫创」（无需登录）。
3. 同样在设置里配置模型与数据目录。

## 数据目录

**设置 → 存储位置**：选择便携数据根（项目与素材在此）。更换目录不会自动迁移旧数据。

## 说明

- 无云登录、无好豆、无系统模型代理。
- 自动更新默认关闭。
