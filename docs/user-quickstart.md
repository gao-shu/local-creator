# 本地漫创 · 快速上手（试用）

## 源码启动

```bash
npm install
npm run dev
```

## 首次运行向导

新数据目录 / 未完成引导时，启动后会弹出向导：

1. **存储位置**：选择便携数据根（项目与素材在此；更换目录不会自动迁移旧数据）。  
2. **配置模型**：至少添加一个 LLM **或** 图片模型（OpenAI 兼容等），填 Endpoint + API Key。  
3. **测试连接**：通过后再进入首页；失败时会显示可读错误。确需跳过须二次确认。

也可稍后在 **设置 → 存储位置 / 模型** 中修改。

## 配置模型（补充）

第三方 API **费用自理**；本软件不提供云模型或充值。

1. 打开 **设置 → 模型**。  
2. **LLM / 图片 / 视频**：添加模型 → 选平台预设或 OpenAI 兼容 → 填 Endpoint + API Key + 模型名。  
3. 点「测试」确认连通后再去工坊 / 画布生成。

## 安装包（若有人发给你 Setup）

1. 运行 `本地漫创 Setup x.x.x.exe`。  
2. 打开「本地漫创」（无需登录）。  
3. 按向导或设置完成数据目录与模型配置。

## 成片

- 优先：工坊 / 画布 **导出剪映（CapCut）草稿**。  
- 规划中：无剪映时的 **最小导出 MP4**（开源核能力，见产品决策 D5；实现节点 OB3）。
