# 本地漫创 · 快速上手（熟人私发）

## 安装

1. 运行 `本地漫创 Setup x.x.x.exe`（当前用户安装即可）。
2. 桌面快捷方式打开「本地漫创」。
3. **无需登录**；首次进入工作台即为本地模式。

## 配置模型（必做）

第三方 API **费用自理**；本软件不提供公司云模型或充值。

1. 打开 **设置 → 模型**。
2. **LLM**：「添加模型」→ 选 OpenAI 兼容 → 填 Endpoint + API Key + 模型名。
3. **图片 / 视频**：同样添加；或视频页点「微视API」填自备微视 Key。
4. 点「测试」确认连通后再去工坊/画布生成。

## 数据目录

设置 → 存储位置：选择一个文件夹作为便携数据根（项目与素材都在此）。更换目录不会自动迁移旧数据。

## 说明

- 无公司云登录、无好豆、无系统模型代理。
- 自动更新默认关闭；新版本由发布者另行发放安装包。
- 问题反馈：当前版本无内置反馈通道，可向给你安装包的人询问。
