# 01 · 产品愿景

## 一句话

把现有 Electron 影视/漫创客户端，改成：**用户自备 API Key、无公司服务器、可开源的本地桌面创作工具**；以后再基于同一能力做商业版增值。

## 两个产品线（后期）

```text
                    ┌─────────────────────┐
   公司仓 haode-ai-client（只读考古，不再承载本地开源版）
                    └─────────────────────┘
                              │ 复制一次
                              ▼
                    ┌─────────────────────┐
                    │  local-creator      │
                    │  开源底子（删公司耦） │
                    └─────────┬───────────┘
                              │
              ┌───────────────┴───────────────┐
              ▼                               ▼
     公开开源版（免费）                 商业版（另仓/私有模块）
     自备 Key / 社区                  增值能力、支持、可选云
```

## L2 成功标准（熟人版私发）

1. 安装后**无需公司账号**即可进入工坊/画布。
2. 用户在设置中配置自己的 LLM / 生图 / 视频模型（含微视等第三方 Key）能跑通至少一条：生图或生视频。
3. 安装包/快捷方式使用占位名「本地漫创」（或已替换的正式名）。
4. 代码中**不存在**可运行的好豆充值、公司系统模型代理、公司微信登录主路径（已删除，而非仅 UI 隐藏）。
5. 仓库仍可保持**私有**；不主动对外宣传。

## 「删除」与「隐藏」的区别（开源硬性要求）

| 做法 | 是否接受 |
|------|----------|
| `if (false)` / 环境变量关掉 UI，文件仍在 | **L2 开源底子不可接受**（最终须删） |
| 设置里去掉入口，lib 仍调用 `/client/haodou` | **不可接受** |
| 删除服务、组件、路由、类型，编译通过且无引用 | **接受** |
| 迁移期短暂保留 dead code 并在 P2 清单勾掉 | 仅允许在 P2 未完成前 |

## 与公司仓对照规则

- 允许：阅读 `../haode-ai-client` 理解原实现。
- 禁止：把本地版提交推进公司远程；禁止把公司 `.env`、密钥、内网地址拷进开源历史。
- 复制代码后：立即在本仓改 `appId`/产品名占位，并开始 P2 删除，避免「开源时还带着好的漫创与公司 API」。
