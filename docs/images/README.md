将下列 PNG 放到本目录；根 [README.md](../../README.md)「截图」节会引用同名文件。

| 文件名 | 内容 | 建议尺寸 |
|--------|------|----------|
| `01-home.png` | 首页（工坊 / 画布入口） | ≥1280×720 |

## 拍摄注意

1. `npm run dev` 或安装包启动后截取当前 UI。  
2. **勿包含真实 API Key**（可用 `sk-****` 或空白输入框）。  
3. 勿带个人项目素材、客户样例路径。  
4. 放入本目录后，可将根 README 表格改为直接 Markdown 图片引用，例如：`![首页](docs/images/01-home.png)`。
