## 明确不做（L2 / 开源一期内）

- 即梦本地（Playwright / SESSION_ID 非官方桥）
- 完全离线本地大模型推理
- 微信登录 / 好豆 / 公司系统模型代理（应删除而非开关）
- 使用公司 ICP、公司下载域名、公司更新 CDN 作为正式渠道
