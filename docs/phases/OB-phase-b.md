# OB · Phase B（30～60 天）可传播 + 可回流

> **依赖**：OA 阶段验收通过（人签字）。  
> **横切**：[oss-gtm-review-rubric.md](../oss-gtm-review-rubric.md)  
> **指挥**：`执行 OB` / `执行 OB1` … `OB 阶段验收`

## 阶段目标

具备**可传播素材**（示例项目、稳定剪映路径、对外官网/落地页）与**回流漏斗**（关于页链仓库、商业咨询入口、固定发版节奏）。  
下载/试用用户知道「如何反馈」「如何找你们」。

## 阶段完成定义（DoD）

- [ ] OB1～OB8 按下方「可裁剪」规则通过  
- [ ] 阶段验收勾选完成  
- [ ] 至少 1 条对外演示内容上线（人或运营勾选）

### 可裁剪规则

| 节点 | 是否可延期到 OC | 条件 |
|------|-----------------|------|
| OB3 最小导出 MP4 | 可 | 仅当 D5 =「只深耕剪映」且人书面豁免 |
| OB7 内容弹药 | 可部分 | 至少 1 条视频或图文；其余可后补 |
| 其余 | 不可 | 必须过人审 |

## OB1 · 内置示例短剧项目

### 目标

用户一键获得可浏览的示例项目（剧本/分集/资产结构完整；生成结果可为占位图或需自备 Key 再生成）。

### 实现方式方案

1. 设计示例包格式（zip 或数据目录模板），放入仓库 `examples/` 或首次复制到 dataRoot。  
2. 向导结束页 / 首页「打开示例」可用。  
3. README 说明示例是否含媒体、是否消耗 API。  
4. 手测：复制后工坊四步可点开不报错。

### 审核标准

| # | 标准 | 级别 | 执行方 |
|---|------|------|--------|
| B1.1 | 存在示例入口且复制成功 | L4 | 人 |
| B1.2 | 示例项目打开无未捕获异常 | L4 | 人 |
| B1.3 | README/向导说明示例边界 | L0 | 人 |
| B1.4 | `compile` 通过 | L2 | AI |

## OB2 · 剪映导出体验打磨（旗舰路径）

### 目标

### 实现方式方案

1. 梳理现有 CapCut 导出：缺片、路径、剪映未安装等错误码 → 用户可读文案。

## OB3 · 最小导出 MP4（可选/按 D5）

### 目标

无剪映用户也能带走拼接预览片（质量可低于剪映精剪）。

### 实现方式方案

1. 若 D5 = 只深耕剪映：本节点写「豁免」到验收记录并跳过实现。  
2. 否则：FFmpeg 按分镜序拼接已生成视频/图片序列 → 输出到项目目录；UI 入口「导出预览 MP4」。  
3. 明确限制：无复杂转场/字幕则可。  
4. 脚本或手测一条 happy path。

### 审核标准

| B3.0 | D5 豁免书面记录 | L0 | 人 |

| B3.2 | 无素材时错误提示明确 | L4 | 人 |
