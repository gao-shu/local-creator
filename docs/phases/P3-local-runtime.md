# P3 · 纯本地运行时

## 目标

应用默认即本地创作工具：无公司服务器假设；用户只配自己的模型 Endpoint + Key。

## 前置

- [x] P2 验收通过

## 操作步骤

### 1. 会话与路由

1. 启动 bootstrap 只走本地用户（可保留/重命名原 `OFFLINE_LOCAL_*`）。
2. `AuthGuard`：永不跳转公司登录页（或登录页改为「配置说明」）。
3. 删除 `VITE_LOGIN_REQUIRED` 双模式文档与分支，避免开源用户误开公司云。

### 2. API Base

1. `apiBaseUrl`：不再指向公司默认生产地址；设置里可空或仅用于「可选自建后端」（默认空）。
2. 清理 `api-base.ts` 中公司域名硬编码与「打包陈旧域名」迁移逻辑里的公司 host。

### 3. 模型体验

1. 首次空模型列表时：设置页引导「添加 OpenAI 兼容 / 微视」文案（占位产品名）。
2. 确认 LLM / 生图 / 生视频自定义模型路径可跑（用你自己的 Key 测）。
3. 微视：保留用户 Key 直连；去掉任何公司中转假设。

### 4. 数据目录

1. 便携数据根文案去掉「好的漫创」前缀（P4 可再统一）。
2. 确认项目创建、画布保存不依赖 `/client/`。

### 5. 编译与手测

```powershell
npm run compile
npm run dev
```

手测清单：

- [x] 启动进首页/工作台（代码：AuthGuard 仅本地 bootstrap；登录页重定向 dashboard）
- [ ] 设置 → 添加一个 LLM → 工坊或画布能调通（任选一条最小路径 · 需你本机 Key）
- [x] 无好豆、无系统模型、无登录二维码
