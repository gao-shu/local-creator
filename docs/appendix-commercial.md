# 附录 · 商业版（后期）

开源底子稳定后再做。**不要**在开源仓里藏商业后门。

## 推荐关系

| 方案 | 说明 |
|------|------|
| **A. 另私有仓** | 从开源版 tag 拉取，私有模块用 submodule 或 npm 私有包（推荐清晰） |
| B. 同仓私有分支 | 易泄露，不推荐 |
| C. 开源核心 + 专有插件协议 | 适合以后扩展市场 |

## 商业版可增值方向（示例，未立项）

- 官方模型代理 / 一键额度（你自己的后端，非原公司）
- 优先支持、私有 Skill 包
- 团队模板与素材库同步
- 安装包代码签名与自动更新 SLA

## 与开源义务

- 若使用 GPL 类许可证，商业闭源分发需合规评估；许可证在开源附录选定。
- 商标与产品名与开源版可区分（如「本地漫创」vs「本地漫创 Pro」）。
