# 本地漫创（local-creator）

与公司仓 `haode-ai-client` **同级**的独立项目。目标是做成可自用、可发给熟人的**本地桌面版**，并在清理干净后**开源**；商业版另起，不与公司后台耦合。

| 项 | 当前占位（可改） |
|----|------------------|
| 文件夹 / 仓库名 | `local-creator` |
| 产品展示名 | 本地漫创 |
| appId | 发熟人包前再定死 |
| 对外公开 | **否**（先私有开发） |

## 原则

1. **不在** `../haode-ai-client` 上改本地版业务；该公司仓仅作只读参考。
2. 公司后台相关能力（登录云、好豆、系统模型代理、公司上传/审核等）目标是**删除代码**，不是长期「隐藏开关」。
3. 文档优先（Phase 0）→ 再拷贝代码 → 再删耦与验收。
